02 — Color System
Hex Codes & Usage Rules

Seven colors make up the entire J12 palette. Brand Black is the default for every surface. Green and Gold are the only accents — never combine them in the same asset.

#6CCF6D — J12 Green
Public series accent. One green element per visual zone. CTAs, icon borders, wordmark accent line, subtitle word highlights. Never combine with gold in the same asset.
#E0B86D — J12 Gold
Internal ecosystem only. Value sequences, proposals, SOPs, portals, client documents. Never combine with green in the same asset.
#5B8DEF — J12 Blue
Hyperlinks and functional UI elements only. Never decorative. Not part of either brand series.
#F5F4F0 — Off White
All primary text on dark backgrounds. Full opacity for headings. 55–75% opacity for body copy. 28–35% for domain labels and tertiary text. Never use pure #FFFFFF.
#141414 — Brand Black
Default background for every surface without exception — video frames, email templates, landing pages, social graphics, printed materials. Use #111111 only for gold series assets.
/* ── J12 CSS Custom Properties — paste into every project :root ── */

06 — Usage Rules
Do & Don't

These are the constraints that keep every J12 touchpoint recognizable and premium.

✓ Always Do
Use #141414 for all Green series backgrounds
Use #111111 for all Gold series backgrounds
Pick one accent (green or gold) per asset — never both
Use J12-Horizontal.png for nav bars, footers, slide headers
Use J12-Full_Display.png for video intros and email heroes
Scale logos proportionally with no cropping
Let the editorial marks breathe — wide clear space around them
Use Cormorant Garamond for all display type
Keep Inter for body text at 13–15px with line-height 1.7
Use Space Mono only for labels, tags, and eyebrows — always tracked uppercase
✕ Never Do
Place green and gold accent elements in the same asset
Use pure #FFFFFF — always use #F5F4F0
Add drop shadows or glows to any logo mark
Stretch, rotate, or distort any logo file
Place logos on light backgrounds without approval
Use Cormorant Garamond for body copy or UI labels
Use Inter for display titles or heroes
Use #5B8DEF blue as a decorative color — links only
Mix editorial marks with heavy graphic elements or busy backgrounds
Use any logo outside of its designated series context
